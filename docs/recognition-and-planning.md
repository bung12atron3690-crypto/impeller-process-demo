# 0.3 算法与工艺规则

## 叶轮候选识别：radial-section-v1

输入必须具备可用的单实体体积与离散网格。STL 使用原网格；STEP 使用 B-rep 离散后的网格，曲面离散误差会影响候选特征。

- 轴向：用户选 X/Y/Z；轴心取横向包围盒中心，不做任意轴自动拟合。
- 横向两尺寸之比至少 0.9，高径比处于 0.08–1.2。
- 径向包络半径为顶点到所选轴线的最大距离，不把包围盒宽度直接当作外径，也不推断入口/出口语义。
- 在总高 5% 和 95% 处切片，以 0.50/0.65/0.80 倍半径采样圆环。一端平均材料占比必须超过 95%，另一端低于 50%，作为单侧底盘与开放端的证据。
- 在总高 35%/55%/75% 的三个截面，各取三个半径，每圈采样 720 点。用闭合截面线段的奇偶交点规则判断材料占用，统计连续材料区间。
- 有效圆环要求 4–24 个材料区间、节距变异系数 ≤0.12、材料占比 2%–45%。至少 6/9 个圆环计数一致，覆盖至少两个高度和三个半径，才标记候选。
- 证据一致率是支持圆环占九个圆环的比例，不是统计分类概率。

输出“最小材料弧长/最小空隙弧长”是有限圆环采样值，不是沿法向的叶片厚度、全局最小流道宽度或刀具可达间隙，工艺接口不会自动使用它们。散热件等形状也可能符合模式，候选仍需人工确认。

已验证生成的 4、6、7、9、12 片直叶片正例；圆柱、长方体、法兰、齿轮、双侧盖板和缺片反例。尚无真实叶轮验证集，不能对任意工业模型承诺识别率。根部圆角、曲率、真实流道和薄壁自动测量尚未实现。

## 工艺草案：process-draft-v1

输入来自服务端保存的几何摘要与用户确认的工程参数。几何文件 SHA-256、识别方法、规则版本和输入随参数包导出；完整几何数值和单位来源另存于几何报告。

当前规则仅用于可审阅 Demo：

1. 人工确认叶轮候选；确认材料及工程输入。材料名称不触发自动参数检索，Vc/fz 是用户输入，系统不保证材料适配性。
2. 要求五轴配置，检查圆柱毛坯能包容模型且不超过机床工件尺寸限额；这不是机床运动学/回转碰撞检查。
3. 粗刀名义直径 ≤0.6×人工确认最小流道宽度，从 `[2,3,4,6,8,10,12,16] mm` 中取最大值。这是演示余隙规则，不是可达性证明。
4. 只有根部最小圆角已确认，才选球头刀，要求直径同时 ≤2R 和流道直径上限。
5. 演示规格假设粗刀有效刃长 3D、球头刀 4D；小于模型总轴向包络时标记阻断。它是保守的粗筛，不是实际刀具供应商参数，也不等于实际所需加工深度。
6. `n=floor(min(1000×Vc/(π×D), 机床最高转速))`，`F=n×z×fz`。实际 Vc 重新按限幅后的转速计算。球头刀使用名义直径，实际接触直径仍需 CAM 确认。
7. 粗加工 `ap=0.25D, ae=0.20D`；精加工/清根 `ap=ae=0.05D`。人工确认壁厚 <3 mm 时，两者减半。以上比例未经材料、刚度、磨损或振动试验标定，不作为生产推荐。
8. 缺圆角时精加工/清根参数为空；缺壁厚时显示未完成薄壁约束。三轴、机床尺寸不足、无适配直径、刃长不足等返回 `blocked`。

工艺路线包括基准准备、流道粗加工、叶片/流道精加工、清根、去毛刺与检验。只列策略与参数草案，无刀位点、NC 代码、刀轴姿态和实际刀路。

## 时间和费用

`毛坯体积=π×毛坯直径²×毛坯高度/4`；`去除量=毛坯体积−模型体积`；理想连续粗加工时间 `=去除量/(F×ap×ae)`；对应机时费用 `=时间/60×用户机时单价`。

此模型假设所有去除量都以同一粗加工参数连续加工，未分配给车削、精加工或清根工序。它不是完整加工节拍、保证下界或报价。总工时/总成本保持空值；存在阻断项时理想时间与费用也为空。

## 生命周期

原模型在请求结束后删除。几何摘要（不含预览顶点）存于当前进程内存，最多 32 份、最长 30 分钟；重启失效。当前只支持单个 API worker。客户端工艺请求只有分析 ID，不能替换服务端几何特征。
