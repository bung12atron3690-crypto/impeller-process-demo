# 开发状态与下一步

## 已完成

- 0.1：Next.js/FastAPI 工程初始化、连通检查和运行说明。
- 0.2：STL/STEP 真实几何解析、单位、拓扑、三维预览和 JSON 几何报告。
- 0.3：基于周期截面的叶轮候选识别、候选叶片计数、采样证据表；人工工程输入、机床/刀具约束、工艺参数草案、JSON 参数包与 CSV 工序卡；理想连续粗加工场景估算。

## 重点 1：模型智能解析，仍需推进

1. 获取赛题原文与真实叶轮样件，建立带人工标注的独立验证集。
2. 自动拟合旋转轴、识别轮毂/进出口语义，并覆盖曲叶片、分流叶片和偏心姿态。
3. 真实最小壁厚、流道宽度、根部圆角及曲率测量；保留来源、位置和误差边界，在三维视图上标注证据。
4. 加强自交与拓扑质量检查。当前候选算法不能作为任意叶轮的可靠分类器。

## 重点 4：可执行加工方案，仍需推进

1. 对接实际机床、刀具/刀柄、材料与切削数据库，替换演示规格和未标定切深比例。
2. 结合真实夹具、公差、表面质量要求，完成可达性、变形、刀路与残料验证。
3. 从 CAM 路径计算完整时间、成本和质量约束，再进行方案比较。
4. 接入后处理、机床仿真和试切验证，才可将工艺草案升级为可上机 NC 程序。

当前不宣称已经满足“自动理解任意叶轮”或“生成可直接上机程序”。规则和验证范围见 recognition-and-planning.md 与 validation.md。
