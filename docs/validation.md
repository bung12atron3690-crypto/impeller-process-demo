# 0.3 验证记录

环境：Linux x86_64、Python 3.12、Node.js 24、OpenCascade 7.8（cadquery-ocp 7.8.1.1.post1）。

## 自动化测试

`backend/.venv/bin/python -m pytest backend/tests -q`：59 项通过。

- 通用几何：二进制/ASCII STL、平移后重心、cm/m/inch 换算、开口/反向/多组件网格、重复三角面、STEP 单位与解析曲面、多实体装配。
- 上传 API：正常上传、格式和内容错误、大小限制、任务容量、超时后资源释放。
- 候选识别：4/6/7/9/12 片生成样例、平移和轴向选择、STL 正例、圆柱/长方体/法兰/齿轮/闭式盖板/缺片反例。
- 工艺：转速与进给公式、转速限幅、已确认流道约束、刀具刃长/机床阻断、缺圆角、薄壁参数调整、无效输入、候选确认、缓存来源和过期。

0.3 前端 `npm run lint`、`npm run build` 通过；生产构建中的 TypeScript 检查通过。

## 浏览器验证

使用 Chromium + Playwright 操作实际 Next.js/FastAPI 页面：

- 上传六叶片生成样例，出现叶轮候选及 WebGL 预览。
- 输入测试场景材料和工程参数，生成待审核草案。
- 转速上限设为 1000 rpm，得到 1000 rpm 和 90 mm/min，并展示限幅依据。
- 根部圆角留空，精加工参数为空并展示说明。
- 下载 JSON 参数包和 CSV 工序卡；核对文件 SHA-256、转速、进给与非 NC 标志。
- 390 px 移动视口无横向溢出。
- 修改输入后旧草案清空；三轴配置生成阻断结果。
- 改传圆柱后回到通用模式，不显示叶轮工艺表单。
- 页面无未捕获 JavaScript 异常。

此前 0.2 已验证几何显示、报告下载、STL 英寸换算和损坏文件反馈。

## Docker 部署验证

前后端镜像构建通过。通过 Compose 的 Nginx 统一入口再次完成上述浏览器流程，无 JavaScript 异常；健康接口可访问，样例下载与源文件字节一致。网关健康探针直接访问容器回环地址，避免环境代理干扰。本次验证在开发环境完成，尚未部署到阿里云 ECS。

工艺测试中的工程输入用于验证公式和约束逻辑，不是生成样例的制造实测数据。以上均未完成真实叶轮识别验证、切削试验或 CAM/NC 验证。
