# 几何校验样例

这些是由代码生成的几何基准件及简化直叶片样例。后两者只验证周期识别逻辑，不代表真实叶轮或制造能力。

| 文件 | 预期结果 |
| --- | --- |
| box-10x20x30-mm.step | 尺寸 10×20×30 mm；面积 2200 mm²；体积 6000 mm³；重心 (5,10,15) mm；6 面、12 边、8 顶点 |
| box-10x20x30-mm.stl | 选择 mm 后，与 STEP 基准件相同尺寸、面积、体积和重心；12 个三角面 |
| cylinder-r5-h20-mm.step | 半径 5 mm，高 20 mm；体积 500π mm³；面积 250π mm²；1 个圆柱面、2 个平面 |
| open-box-mm.stl | 缺少一个三角面的开口网格；体积和重心必须显示不可用 |
| synthetic-impeller-6-mm.step | 轴向 Z；6 个周期叶片；径向包络约 120 mm、总高 30 mm；应为叶轮候选 |
| synthetic-impeller-7-mm.step | 同尺寸，7 个周期叶片；应为叶轮候选 |

简化叶轮由底盘、轮毂和直叶片通过布尔融合组成单实体，根部没有设计圆角。当前不自动测出其最小流道间隙或壁厚；工程输入须独立测量，测试参数不代表模型真实加工要求。

重新生成：在仓库根目录执行 `backend/.venv/bin/python backend/scripts/generate_samples.py`。
